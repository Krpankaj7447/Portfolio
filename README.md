# Pankaj Kumar - Premium Professional Portfolio

Welcome to my personal portfolio repository! This website is a fully responsive, modern, and premium portfolio designed to showcase my skills, projects, certifications, and experience as a Full-Stack Developer and Data Engineer.

## 🔗 Live Demo
You can view the live site here: **[https://krpankaj7447.github.io/Portfolio/](https://krpankaj7447.github.io/Portfolio/)**

## ✨ Key Features
- **Premium Aesthetics:** Curated dark mode with gold accents, smooth layouts, and elegant typography.
- **Fully Responsive:** Optimised and tested for all devices including mobile screens, tablets, laptops, and desktop monitors.
- **Scroll Animations:** Interactive viewport entrance animations using the native JavaScript `Intersection Observer` API.
- **Mouse-Follow Tilt Effect:** Interactive mouse hover 3D tilt effects on certificate cards.
- **Direct Mail Contact Form:** Fully verified and operational client-side form that redirects to email dispatcher dynamically.

## 🛠️ Technologies Used
- **Frontend Core:** HTML5, Vanilla CSS3 (Custom Grid/Flexbox Layouts)
- **Logic & Effects:** Vanilla JavaScript (ES6+)
- **Icons:** Lucide Icons Library

## 📂 Project Structure
- `index.html` - Core structure and semantic elements of the website.
- `style.css` - Custom premium variables, styling, page layout, transitions, and media query responsiveness rules.
- `script.js` - Scroll animations, interactive tilt calculations, contact form validation, and event handling.
- `photo/` - Profile photography assets.
- `logo/` - Brand header logo assets.
- `certificate/` - High-resolution PNG certification cards.
- `infravision/` - Project video demonstrations.
